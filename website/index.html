Your files stay in this tab. Local snapshots are read in browser memory. No file upload, account, analytics, or model call. Loading the bundled demo fetches only this site’s synthetic fixture.

Integrity is one layer. This independent reader checks hashes, references, and history. It does not evaluate authorization or authenticate owners. A checkpoint bundled with a package is a consistency check; a separately trusted checkpoint can anchor history.

How do I open my own .gpt package?

Export a browser snapshot locally with the Python tool, then choose “Open your snapshot.” Raw SQLite files are not opened directly by this inspector.

python tools/browser_snapshot.py project.gpt project.snapshot.json --checkpoint project.checkpoint.json

The checkpoint option is optional. Use “Add external checkpoint” to check a separately retained checkpoint. Browser input is limited to 32 MiB. See compatibility and limitations.

python tools/portable.py import notebook restored.gpt
python tools/portable.py verify restored.gpt --policy
